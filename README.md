# Alltrek Tentastic M — Viewer 360°

Viewer 3D interaktif setup "Tenda Premium" (semi glamping) dengan tenda Alltrek Tentastic M untuk Taman Wisata Alam Gunung Pancar. Buka `index.html`, atau versi online lewat GitHub Pages.

- Satu file HTML, berjalan langsung di browser tanpa instalasi (three.js, WebGL 2).
- Mode: Original, Hutan 360°, Tour, Jalan masuk, Interior 360°, Denah 3D, Edit layout.
- Susunan awal mengikuti deck presentasi: kasur cokelat, bohlam mini di kanopi, welcome tray dan Guest Service Directory Book di meja amenities, nesting set dan pan grill, kompor dan gas, sandal gunung, dan pouch di atas kasur.
- Perubahan di Edit layout tersimpan di browser masing-masing pengunjung saja.

Dibuat dari folder `v3` dengan `node build.mjs web`.
